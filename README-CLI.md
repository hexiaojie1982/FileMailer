# FileMailer CLI 版使用指南 (FileMailer-CLI.exe)

**FileMailer-CLI.exe** 是专为无需要图形界面的**服务器部署、计划任务 (Crontab / Windows 任务计划程序) 自动化调用**设计的命令行版本。它保留了全部底层引擎的能力（分卷压缩、绕过限流封顶封装、断线重试自救及断点续发），并允许开发人员完全通过外部传参静默驱动发信引擎。

---

## 🛠️ 基本使用前提

在使用命令行静默发送前，**必须**满足此先决条件：
您曾在带界面的系统中（双击打开程序或普通版 GUI）**成功添加并保存过发件人的邮箱账号及密码配置**。CLI 程序运行时，需要调用这些本地安全凭证数据脱机工作。

---

## 📖 核心命令格式

启动 CLI 引擎必须在第一个参数传入 `--cli` 指令，否则程序会尝试调起图形界面资源。

```bat
FileMailer-CLI.exe --cli [可选与必选参数...]
```

### 必填项 (开始全新任务必备)

| 参数代码 | 描述说明 | 样例写法 |
| :--- | :--- | :--- |
| `--files` | 指定需要压缩发送的单个或多个文件、目录路径（多路径以空格分隔） | `--files "C:\Data.mp4" "D:\Backup"` |
| `--to-addrs` | 指定收件人的完整电子邮箱地址（多人可用半角逗号分隔） | `--to-addrs "admin@qq.com,test@163.com"` |
| `--account` | 指定本次发件的账号载体（填入您在 GUI 曾配置的**账号别称**或发件邮箱） | `--account "工作汇报一号机"` |

### 选填项与高级配置 (Advanced Config)

| 参数代码 | 默认值 | 描述说明 |
| :--- | :--- | :--- |
| `--subject` | 自动取文件名 | (选填) 覆盖自定义该批邮件的主题前缀。 |
| `--volume` | `10` | (选填) 分别按多大的体积(MB)进行切片分卷。严格邮箱建议 10-20MB。 |
| `--password` | (无) | (选填) 对整体压缩文件加上解压密码屏障。 |
| `--interval` | `30` | (选填) 每发送成功一封与下一封的停顿间隔时长(秒)，防被识别为垃圾频发。|
| `--max-retries` | `10` | (选填) 网络因高墙阻断或瞬间丢包报错，允许引擎在本地自我努力抢救的重投次数。|
| `--retry-wait` | `15` | (选填) 触发重连时，进入多少秒(s)的冷静休眠等待时间。 |

---

## ⚠️ 无人值守保护网：超时倒计时 (`--prompt-timeout`)

自动化程序最忌讳遇到报错后卡死弹出对话框死等用户键入 `[Y/N]`，这会导致服务器进程堵塞。<br/>
因此，本 CLI 引入了倒计时自毁炸弹参数 `--prompt-timeout` (默认 `30`秒)。

**触发时机：** 
当您的包发到一半时网络连接枯竭，且您设置的重连防波堤次数 `--max-retries` 已全被耗光后。引擎会向控制台吐出黄字警告并开始倒计时。
- 如果是您在旁边人工照看：支持立即在终端打出 `Y` 抢救一次。
- 如果是在服务器静默状态下：三十秒读秒到底后，它将遵循机器人底层协议，**默认执行 `N` (强行回退清理临时文件、抹除当前发送状态快照)，并干净利落地让出内存退出 (`sys.exit`)**。

您可以手动调整该倒计时长度：
```bat
# 设定为 5 秒不响应立刻清后台跑路
FileMailer-CLI.exe --cli --files "D:\Doc" --to-addrs "c@c.com" --account "acc1" --prompt-timeout 5
```

## 🚑 王牌指令：真·无损断点衔接发包 (`--resume`)

如果您昨晚的任务跑了一半因为网络原因彻底失败并中止运行了，今早只要您当初的临时文件夹还在（没被人工清理），您只需向 CLI 系统敲下以下救急指令：

```bat
FileMailer-CLI.exe --cli --resume --account "新的救急小号"
```

**执行逻辑：**
完全跳过多达十几分钟乃至半小时的巨大压缩运算。立刻从中断处的下一个快照节点继续提取封包向外进行发配。甚至**允许中途直接换车**（您可以使用一个新的备用 `--account` 账号名填上去，它就立马换备用邮箱向外继续输出进度）。
