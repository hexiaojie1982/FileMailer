# 📦 文件分卷压缩 & 邮件自动发送工具 (File Mailer)

这是一款基于 Python 开发的带用户图形界面 (GUI) 的桌面端实用工具。它能将单个大文件或整个文件夹自动切割、加密并压缩为多个 `.7z` 分卷压缩包，最后依序自动通过电子邮件发送给一个或多个收件人。

本工具不仅解决了国内/外邮箱附件大小受限的痛点，还利用多种反拦截策略成功帮助您顺畅发送大文件。

---

## ⚡ 核心功能特色

- **无感分卷与压缩**：自动利用高强度 `7-Zip` 算法压缩并分卷，可自设任意解压密码或不设。
- **发送防拦截引擎**：针对类似 Gmail 一类具有极其苛刻安全审核机制的邮箱，本工具使用 **Zip 嵌套封装技术** 完美骗过引擎扫描。
- **智能化 SMTP 发信**：预置 QQ、163、Gmail 等多种主流行配置，一键配置授权码；全自动判断发信端口使用 `SSL` 或是 `STARTTLS` 防止连接崩溃。
- **账号多密钥加密**：配置的邮箱授权码信息存储在本地，并受 AES-128 对称加密技术严格保护。（通过独有的 `.secret.key` 加解密）。
- **用户习惯全记忆**：不论是你的解压密码、上一次填写的收件人还是最近发信的邮箱，工具全部自动持久化在本地。

## 💻 运行要求与环境准备

在首次使用前，请确保您已在计算机上安装 **Python 3.8+**，并在终端（Terminal）执行以下命令以安装必需的依赖库：


## 📖 图文使用教程

### 第一步：配置发件邮箱 (首要必做)
本程序本身不提供公共线路，需要您自己提供一个合法的发件邮箱作为发送方。
> **⚠️ 微软邮箱警告**：因微软已经全球淘汰基础账密协议，如果使用 Outlook / Hotmail **必将严重报错无法发件**。请强烈推荐使用 **Gmail / QQ / 163 等邮箱**配合其【应用专用密码/授权码】进行发件。

1. 在主界面中，找到 “✉️ 邮件设置” 区域，点击 **⚙ 管理账号**。
2. 在弹窗底部，**邮箱预设**处选择您的邮箱服务商（如 Gmail）。
3. 填入您的邮箱地址。然后在**授权码**一栏，贴入您在邮箱安全设置里刚刚申请到的 16位应用密码。
4. 点击“保存新账号”，即可在列表里看到它！随后直接关闭弹窗。
5. 在主界面的 **发件账号** 下拉框里，选中它作为当前的发件人。

### 第二步：选择待处理的文件与压缩设置
1. 点击 **选择文件** 或 **选择文件夹**，您可以随意组合挑出需要发送的内容。如果不小心选错了，可以选中列表项后点击“🗑 移除选中项”或“全部清空”。
2. 配置**分卷大小 (MB)**：
   - 国内邮箱（如163/QQ）：通常单封附件最大支持 50MB。建议设置为 `25` 或 `30`。
   - 海外邮箱（如Gmail）：普通单封附件最大只能容纳 25MB。**强烈建议本工具分卷设置为 `10` 或 `15`，以保障发送成功率。**
3. （可选）为您的压缩包指定一个 **解压密码**，增强内容传递的隐私性。

### 第三步：添加收件人并开始发送
1. 在 **收件人** 一栏输入对方的邮箱（若要发给多人，请用半角逗号 `,` 间隔）。
2. 按回车或点击“➕ 添加”，他们将会加入下方发件列表。
3. 一切就绪后，点击底部那个巨大的绿色按钮：**▶ 开始压缩并发送**！
4. 随后，请您离开座位喝杯水。程序将把文件压缩成分卷 `xxx.7z.001` 等后缀，并自动帮它们套上一层防拦截防杀毒 `.zip` 伪装壳，依序发给指定的客户。

*(发送成功后，您会在底部的日志窗口里看到圆满结束的绿色提示。)*

## ❓ 常见问题汇总

### 1. 为什么我双击了刚刚下方的重置按钮，它却没有彻底重置我的发件人信息？
主界面的“🗑 还原设置”功能是为了快速清空你的缓存（比如填腻了的几十个收件人邮箱、历史解压密码），而不会干预你辛苦去邮箱后台申请的配置！
如果需要彻彻底底把某个邮箱从电脑里拉黑或更新密码：请点击 **⚙ 管理账号** 并在里面选择删除或双击重新更新。

### 2. 朋友收到邮件后，怎么解压这个所谓的双重压缩包？
非常小白友好：
- 第一步，对于所有收到的附件：先利用 Windows 系统**自带**的双击提取，或者右键“提取到当前文件夹”把所有的 `.zip` 脱壳。他们会自动得到很多真正的 `.7z.001`, `.7z.002`... 等文件。
- 第二步，确保所有的 `.00X` 分卷文件在**同一级目录**，然后鼠标右键点击 `.001` 那个文件，使用著名的开源软件 `7-Zip` 点击“提取文件”即可。如果设置了密码，此时 7-Zip 将会提示输入。

### 3. 如果我误删了目录下的 `.secret.key` 怎么办？
本软体将账户全部做了军事级加密保存在 `accounts.json`。这个 `.secret.key` 就是全世界唯一能解锁那堆配置的钥匙。
- 如果钥匙丢失：过去的加密数据报废，您在列表里将无法解析过往添加的任何邮箱账号。
- **补救措施**：删掉它旁边的 `accounts.json`，打开软件重新把发件账号去添加一遍吧！
